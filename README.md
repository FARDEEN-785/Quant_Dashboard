# Crypto Strategy Dashboard

A simple yet elegant web dashboard built with Flask to showcase a sample crypto trading strategy. The project reads data from a CSV file and displays key trading signals, trend strength, and charts, making it easy to analyze market trends.

---

# Features

- Upload your own CSV file (with Date, Signal, Close, Trend_Strength columns)
- Displays:
  - Buy/Sell signals
  - Trend strength indicators
  - Line chart of signal over time
  - Clean tabular view of the data
- Dark-themed modern UI with minimal CSS
- Built using Python, Flask, pandas, matplotlib, and HTML/CSS

---

# Tech Stack

- Python 
- Flask 
- pandas 
- matplotlib 
- HTML/CSS
